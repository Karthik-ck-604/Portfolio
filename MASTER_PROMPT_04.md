# MASTER_PROMPT_04.md

# Skills & Featured Projects Specification

> Purpose: Demonstrate technical depth through an engaging presentation
> of skills and real-world projects.

------------------------------------------------------------------------

# 1. Section Flow

1.  Skills Intro
2.  Technical Categories
3.  Featured Technologies
4.  Featured Projects
5.  Project Gallery CTA

------------------------------------------------------------------------

# 2. Skills Philosophy

Present skills as capabilities, not keyword lists.

Goals: - Easy to scan in under 30 seconds. - Highlight strengths. - Show
breadth without overwhelming.

------------------------------------------------------------------------

# 3. Skills Layout

Desktop: - Two-column layout. - Left: introduction. - Right: technology
groups.

Tablet: - Single column with grouped cards.

Mobile: - Accordion or stacked cards.

------------------------------------------------------------------------

# 4. Categories

Languages - JavaScript - TypeScript - Java - Python

Frontend - React - Tailwind CSS - HTML5 - CSS3

Backend - Node.js - Express.js - Spring Boot - REST APIs

Database - MongoDB - MySQL

Testing & Quality - Postman - Selenium - Playwright

Cloud & AI - Oracle OCI - AWS - Gemini API - Ollama

Developer Tools - Git - GitHub - Vite - VS Code

------------------------------------------------------------------------

# 5. Skill Cards

Each card contains: - Icon - Category title - Technology chips - Short
description

Hover: - Border changes to accent. - Slight lift. - Soft shadow.

------------------------------------------------------------------------

# 6. Featured Technologies

Highlight: - MERN Stack - Spring Boot - AI Integration - Cloud
Deployment

Display as premium badges with supporting text.

------------------------------------------------------------------------

# 7. Projects Section

Heading: FEATURED PROJECTS

Subtitle: Selected work demonstrating engineering, design, and problem
solving.

------------------------------------------------------------------------

# 8. Layout

Desktop: Large alternating showcase cards.

Tablet: Stacked image-first cards.

Mobile: Vertical cards.

------------------------------------------------------------------------

# 9. Project Card Structure

Header - Project name - Category - Status - Year

Overview - Problem - Solution - Outcome

Technology Stack - Chips

Highlights - 3--5 key features

Actions - Live Demo - GitHub - Case Study (optional)

------------------------------------------------------------------------

# 10. Visual Design

Images: - Rounded corners. - Consistent aspect ratio. - Lazy-loaded. -
Hover zoom.

Background: Dark surface.

Accent: Crimson only for active states.

------------------------------------------------------------------------

# 11. Motion

Section reveal.

Card stagger.

Image zoom on hover.

CTA arrow translation.

Optional sticky card stack using Framer Motion.

------------------------------------------------------------------------

# 12. Content Rules

Every project should answer: - What was built? - Why was it built? -
Technologies used. - Biggest challenge. - Result.

Avoid generic descriptions.

------------------------------------------------------------------------

# 13. Project Priority

1.  Meet-IQ
2.  Ben 10 Interactive Portfolio
3.  Car AI Dashboard
4.  Student Management System
5.  Portfolio Website

Each project should include screenshots and measurable outcomes where
possible.

------------------------------------------------------------------------

# 14. Responsive Behaviour

Desktop: Alternating media/text layout.

Tablet: Single-column.

Mobile: Buttons full width. Chips wrap naturally.

------------------------------------------------------------------------

# 15. Accessibility

Keyboard focus for buttons.

Meaningful alt text.

Minimum 44px touch targets.

------------------------------------------------------------------------

# 16. Performance

Optimize screenshots.

Use responsive image sizes.

Lazy-load all non-visible media.

------------------------------------------------------------------------

# 17. Component Hierarchy

SkillsSection ├── SectionHeading ├── SkillsIntro ├── SkillGrid └──
TechnologyHighlights

ProjectsSection ├── SectionHeading ├── ProjectGrid │ └── ProjectCard ├──
CTAButtons └── MoreProjectsLink

------------------------------------------------------------------------

# 18. Acceptance Criteria

Visitors should: - Understand the primary technology stack quickly. -
Recognize engineering capability through projects. - Be encouraged to
explore GitHub or live demos. - Experience smooth interactions across
all devices.
