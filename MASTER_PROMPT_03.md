# MASTER_PROMPT_03.md

# About & Experience Specification

> Purpose: Transform a resume into a compelling professional story.

------------------------------------------------------------------------

# 1. Section Order

1.  About
2.  Core Values
3.  Career Timeline
4.  Experience Timeline
5.  Achievements Banner

------------------------------------------------------------------------

# 2. About Section

## Objective

Help visitors understand: - Who Karthikeyan C is - What problems he
enjoys solving - Why he builds software - What makes his approach
different

The section should read like a narrative rather than a biography.

------------------------------------------------------------------------

# 3. Visual Direction

Inspired by premium editorial layouts.

Avoid copying any reference exactly.

Design characteristics: - Large typography - Editorial whitespace -
Split layout - Floating accent shapes - Subtle depth - Black / crimson /
white palette

------------------------------------------------------------------------

# 4. Layout

Desktop: - 12-column grid - Left: portrait or abstract illustration -
Right: heading + story

Tablet: - Portrait above content

Mobile: - Single-column - Center aligned image - Left-aligned text

------------------------------------------------------------------------

# 5. Heading

Title: ABOUT

Subtitle: Building software with curiosity, structure, and purpose.

Typography: - Space Grotesk - Clamp sizing - Tight leading

------------------------------------------------------------------------

# 6. Story Content

Use four short paragraphs.

Paragraph 1 Introduce current identity.

Paragraph 2 Journey from student projects to internships.

Paragraph 3 Interest areas: - Full Stack - MERN - Spring Boot - AI -
Cloud

Paragraph 4 Career objective: Build reliable products that solve real
problems.

Maximum width: 680px.

------------------------------------------------------------------------

# 7. Highlight Cards

Four cards.

• Full Stack Development • REST API Design • Cloud & AI • Clean UI
Engineering

Each card contains: - Icon - Title - Two-line description

Hover: - Lift 4px - Border accent - Soft glow

------------------------------------------------------------------------

# 8. Core Values

Grid of four principles.

-   Simplicity
-   Performance
-   Accessibility
-   Continuous Learning

Cards animate independently.

------------------------------------------------------------------------

# 9. Experience Section

## Heading

EXPERIENCE

Subtitle: Practical industry exposure through internships and projects.

------------------------------------------------------------------------

# 10. Timeline Layout

Desktop: Vertical center timeline.

Mobile: Single-column cards.

Each timeline item contains:

-   Role
-   Company
-   Duration
-   Technologies
-   Responsibilities
-   Key achievements

------------------------------------------------------------------------

# 11. Card Structure

Header - Company - Role - Date

Body - Summary - Technologies - 3--5 achievement bullets

Footer - Skills gained - Optional certificate link

------------------------------------------------------------------------

# 12. Motion

Section reveal: Fade + translateY.

Timeline line: Animated growth on scroll.

Cards: Alternate slide left/right.

Hover: Scale 1.02.

------------------------------------------------------------------------

# 13. Content Rules

Achievements should: - Start with action verbs. - Mention measurable
outcomes where possible. - Focus on engineering work rather than generic
duties.

Avoid long paragraphs.

------------------------------------------------------------------------

# 14. Responsive Behaviour

Desktop: Alternating timeline.

Tablet: Reduced spacing.

Mobile: Stack cards. Hide decorative elements only.

------------------------------------------------------------------------

# 15. Accessibility

Use semantic sections.

Timeline remains readable without animation.

Icons marked decorative where appropriate.

------------------------------------------------------------------------

# 16. Performance

Lazy-load portrait.

Animate only visible elements.

Prefer transform/opacity animations.

------------------------------------------------------------------------

# 17. Component Hierarchy

AboutSection ├── SectionHeading ├── Portrait ├── Story ├── HighlightGrid
└── ValuesGrid

ExperienceSection ├── SectionHeading ├── Timeline │ └── ExperienceCard
└── CTA

------------------------------------------------------------------------

# 18. Acceptance Criteria

Visitors should: - Understand the developer's background within one
minute. - See progression from education to internships. - Recognize
technical growth and professionalism. - Naturally continue to the Skills
section.
