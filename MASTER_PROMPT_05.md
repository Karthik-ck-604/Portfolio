## Objective

Highlight research experience and technical writing.

problem-solving

------------------------------------------------------------------------

PUBLICATIONS

Subtitle: Research contributions and technical publications.

------------------------------------------------------------------------

## Publication Card Structure

Body - 2--3 sentence summary - Technologies or research domain

# 7. Motion Guidelines

-   Sections reveal independently
-   Cards stagger on scroll
-   Buttons use magnetic hover (optional)
-   Social icons scale on hover

------------------------------------------------------------------------

# 8. Accessibility

-   Semantic landmarks
-   Keyboard-accessible links and buttons
-   Focus-visible states
-   Form labels and ARIA descriptions
-   Color contrast AA

------------------------------------------------------------------------

# 9. Performance

-   Lazy-load logos
-   Compress certification images
-   Cache GitHub API requests if used
-   Avoid blocking scripts

------------------------------------------------------------------------

# 11. Acceptance Criteria

The final sections should:

-   Reinforce technical credibility.
-   Highlight continuous learning.
-   Encourage exploration of GitHub.
-   Make contacting the developer frictionless.
-   End the portfolio with a polished, memorable impression.
